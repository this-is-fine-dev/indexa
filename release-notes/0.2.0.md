# Indexa 0.2.0

- Aktualizacje przez Sparkle i podpisane paczki GitHub Releases.
- Wspólna rozmowa bota Indexa w Hermesie i Matrixie; końcowe odpowiedzi z obu kanałów trafiają na telefon.
- Ponawianie wiadomości Matrix bez ponownego uruchamiania zadania.
- Bezpieczniejsze zatrzymywanie usług, ponowne łączenie i obsługa przerwanego startu.
- Czytelniejsze statusy, odpowiedzi w szczegółach zadań oraz otwieranie Hermesa.
- Ręczne odblokowanie niepewnych zapisów do Notatek bez powtarzania operacji.
- Odliczanie i ponawianie połączenia podczas logowania QR; kopiowanie danych i automatyczne czyszczenie schowka z sekretami.
- Retencja lokalnej kolejki, ograniczone zapytania i rotacja logów.
- Kontrola zgodności lokalnych usług, aktualizacja pluginu Notes i odzyskiwanie po przerwaniu tej aktualizacji.

Wymaga już skonfigurowanego środowiska Indexy. Historia Matrix, Hermes i Notatki pozostają poza retencją kolejki. Aktualizator zacznie pobierać wydania anonimowo po upublicznieniu repozytorium. Szczegóły i ograniczenia: `docs/RELEASE.md`.
